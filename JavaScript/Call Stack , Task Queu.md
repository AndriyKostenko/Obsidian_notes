# Очередь задач в JavaScript

JavaScript — однопоточный язык, но он поддерживает асинхронное выполнение через **Event Loop** (цикл событий) и систему очередей задач. Вот как это работает:

## 🧠 Основные компоненты

1. **Call Stack (Стек вызовов)**  
   Выполняет синхронный код. Функции добавляются в стек и удаляются после завершения.

2. **Web APIs / Node APIs**  
   Предоставляют асинхронные возможности (таймеры, запросы, события и т.д.).

3. **Task Queue (Macrotask Queue)**  
   Очередь для макрозадач: `setTimeout`, `setInterval`, I/O, UI-рендеринг.

4. **Microtask Queue**  
   Очередь для микрозадач: `Promise.then/catch/finally`, `queueMicrotask`, `MutationObserver`.

5. **Event Loop**  
   Постоянно проверяет стек и очереди, перенося задачи на выполнение в правильном порядке.

## ⚙️ Порядок выполнения

1. Выполняется весь синхронный код (из стека).
2. После очистки стека:
   - Сначала обрабатываются **все микрозадачи**.
   - Затем — **одна макрозадача**.
3. Цикл повторяется.

## 🧪 Пример кода

```javascript
console.log('1'); // Синхронно

setTimeout(() => {
  console.log('2'); // Макрозадача
}, 0);

Promise.resolve().then(() => {
  console.log('3'); // Микрозадача
});

console.log('4'); // Синхронно
```

**Вывод:**
```
1
4
3
2
```

## 📊 Сравнение очередей

| Характеристика       | Макрозадачи                 | Микрозадачи                    |
|----------------------|-----------------------------|--------------------------------|
| Примеры              | `setTimeout`, `setInterval` | `Promise`, `queueMicrotask`    |
| Приоритет            | Ниже                        | Выше                           |
| Выполнение           | По одной за цикл            | Все перед следующей макрозой   |
| Влияние на рендеринг | Может отложить рендеринг    | Выполняются до рендеринга      |

## 🧩 Пример с приоритетами

```javascript
console.log('Start');

setTimeout(() => console.log('Timeout'), 0);

Promise.resolve()
  .then(() => console.log('Promise 1'))
  .then(() => console.log('Promise 2'));

queueMicrotask(() => console.log('Microtask'));

console.log('End');
```

**Вывод:**
```
Start
End
Promise 1
Promise 2
Microtask
Timeout
```

## ⚠️ Важные нюансы

### 1. Микрозадачи блокируют макрозадачи
```javascript
Promise.resolve().then(function recurse() {
  console.log('Микрозадача');
  Promise.resolve().then(recurse);
});

setTimeout(() => console.log('Никогда не выполнится'), 0);
```
> Бесконечная цепочка микрозадач не даст выполниться макрозадачам.

### 2. Вложенные `setTimeout` — новые макрозадачи
```javascript
setTimeout(() => {
  console.log('1');
  setTimeout(() => console.log('2'), 0);
}, 0);

Promise.resolve().then(() => console.log('3'));
```
**Вывод:** `1`, `3`, `2`

### 3. `async/await` — это микрозадачи
```javascript
async function test() {
  console.log('1');
  await Promise.resolve();
  console.log('2');
}
test();
console.log('3');
```
**Вывод:** `1`, `3`, `2`

## 🎯 Практическое применение

### Обновление UI после микрозадач
```javascript
button.addEventListener('click', () => {
  Promise.resolve().then(() => {
    // Микрозадача выполнится до перерисовки
    updateUI();
  });
});
```

### Контроль порядка выполнения
```javascript
// Сначала все микрозадачи, потом макрозадачи
fetch('/api/data')
  .then(data => processData(data)) // Микрозадача
  .finally(() => hideLoader());    // Микрозадача

setTimeout(() => showNotification(), 0); // Макрозадача
```

## 🔁 Визуализация цикла

```
┌─────────────────────┐
│   Выполняется код   │
│   (Call Stack)      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│   Стек пуст?        │
└──────────┬──────────┘
           │ Да
           ▼
┌─────────────────────┐
│  Микрозадачи        │ ← Все подряд
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Одна макрозадача   │ ← Только одна
└──────────┬──────────┘
           │
           └───────▶ (повтор)
```

## 💡 Ключевые выводы

- Микрозадачи имеют **высший приоритет** и выполняются **все сразу** после очистки стека.
- Макрозадачи выполняются **по одной** за цикл.
- Понимание очередей помогает избежать **гонки условий**, **зависаний** и проблем с **рендерингом**.
- Используйте микрозадачи для **критичных по времени операций**, макрозадачи — для **отложенных или тяжелых задач**.

Понимание работы очередей задач — ключ к написанию эффективного и предсказуемого асинхронного кода в JavaScript.
