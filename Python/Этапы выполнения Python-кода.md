### ASSISTANT
Python часто называют «интерпретируемым», но в стандартной реализации **CPython** код на самом деле проходит несколько этапов перед выполнением. Ниже объясню процесс и покажу схему.

### 🔹 Этапы выполнения Python-кода (CPython)

```
[Исходный код .py]
        │
        ▼ 1. Лексический анализ + Синтаксический разбор
[AST-дерево]  (Abstract Syntax Tree)
        │
        ▼ 2. Компиляция
[Байт-код]  (инструкции для виртуальной машины, кэшируются в __pycache__/*.pyc)
        │
        ▼ 3. Python Virtual Machine (PVM)
[Пошаговое исполнение байт-кода]
        │
        ▼ 4. Взаимодействие с ОС / оборудованием
[Вывод, чтение файлов, вызовы C-библиотек и т.д.]
```

### 🔍 Что происходит на каждом этапе?
1. **Парсинг** → Исходный текст превращается в AST (дерево синтаксических конструкций). На этом этапе ловятся `SyntaxError`.
2. **Компиляция** → AST преобразуется в байт-код. Это не машинный код процессора, а набор инструкций для виртуальной машины Python.
3. **Исполнение в PVM** → Виртуальная машина читает байт-код инструкцию за инструкцией, управляет стеком, памятью, вызывает встроенные функции.
4. **Системный уровень** → Через C-интерфейсы CPython взаимодействует с ОС, сетью, файловой системой и т.д.

> 💡 Файлы `.pyc` создаются **для ускорения**, но не обязательны. Если их нет, Python скомпилирует байт-код в памяти при запуске.

### 📜 Как происходит **поочерёдное исполнение**?

Python выполняет код **строго сверху вниз**, но с важными нюансами:

```python
print("1. Старт")          # ✅ Выполняется сразу

def greet():                # ✅ Выполняется ОПРЕДЕЛЕНИЕ функции
    print("2. Внутри функции")  # ❌ Тело НЕ выполняется пока

print("3. До вызова")       # ✅ Выполняется
greet()                     # ✅ Вызов → переход в тело функции
print("4. После вызова")    # ✅ Выполняется
```

**Порядок фактического вывода:**
```
1. Старт
2. До вызова
3. Внутри функции
4. После вызова
```

### 🔑 Ключевые правила последовательного исполнения
| Конструкция | Когда выполняется? |
|-------------|-------------------|
| Присваивание, вызовы функций, `print`, `import` | Сразу, при достижении строки |
| `def`, `class` | Создаётся объект функции/класса, **тело не запускается** |
| Тело функции/метода | Только при явном вызове `func()` |
| `if/else`, `for`, `while` | Выполняется ветвь/тело, соответствующее условию или итерации |
| `import` | Выполняется полностью при первом импорте, результат кэшируется в `sys.modules` |
| Ошибки выполнения (`NameError`, `TypeError` и т.д.) | Возникают в момент исполнения конкретной инструкции PVM |

### 🧠 Почему это важно понимать?
- ❌ Python **не интерпретирует построчно в реальном времени**. Сначала весь модуль компилируется в байт-код, потом исполняется.
- ✅ Ошибки синтаксиса ловятся до запуска, ошибки выполнения — в процессе.
- 🔁 Внутри функций свой стек вызовов и локальные пространства имён, но порядок исполнения остаётся линейным (если нет асинхронности/потоков).
