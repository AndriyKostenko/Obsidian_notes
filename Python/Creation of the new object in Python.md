### 1. Фундамент: Как выглядит ЛЮБОЙ объект в памяти
В CPython нет отдельного `struct PyObject`, который создаётся сам по себе. Есть макрос `PyObject_HEAD`, который вставляется в начало **любой** структуры.

```c
// Упрощённо на C
typedef struct _object {
    Py_ssize_t ob_refcnt;      // Счётчик ссылок (сколько переменных указывают сюда)
    struct _typeobject *ob_type; // УКАЗАТЕЛЬ на тип (класс) этого объекта
} PyObject;
```

**Схематически в памяти:**
```text
[ ПАМЯТЬ ОБЪЕКТА ]
+-----------------------------+
| PyObject_HEAD               |
|  +-----------------------+  |
|  | ob_refcnt = 1         |  | <--- Сколько ссылок на этот объект
|  | ob_type = [Указатель] |--------> Ссылка на Класс (PyTypeObject)
|  +-----------------------+  |
+-----------------------------+
| ... Специфичные данные ...  | <--- Для int: число, для dict: хеш-таблица и т.д.
+-----------------------------+
```

### 2. Создание Класса (`class A: ...`)
Здесь работает **Метакласс** (по умолчанию `type`).
Метакласс `type` — это тоже объект (типа `PyTypeObject`), который существует при запуске Python.

**Процесс:**
1. Python собирает тело класса в словарь `namespace`.
2. Вызывается `type.__new__()`.
3. Выделяется память под **новый** `PyTypeObject` (это и есть ваш класс `A`).

**Схема:**
```text
[ Метакласс type ]              [ Новый Класс A ] (PyTypeObject)
+-------------------+           +-------------------------------------+
| PyObject_HEAD     |           | PyObject_HEAD                       |
|  ob_type --------->---------->|  ob_type ------------------------+  |
+-------------------+           +---------------------------------+ |  |
| tp_new (функция)  |           | | tp_name = "A"                 | |  |
| tp_init (функция) |           | | tp_bases = (object,)          | |  |
+-------------------+           | | tp_dict = {'method': func}    | |  |
      |                         | | tp_new = ...                  | |  |
      | (вызывает __new__)      | +---------------------------------+  |
      +------------------------>+                                    |
                                +-------------------------------------+
                                ^
                                |
                  (ob_type класса A указывает на type)
```
> **Итог:** Класс `A` — это объект типа `PyTypeObject`, созданный фабрикой `type`.

### 3. Создание Экземпляра (`a = A()`)
Теперь мы используем Класс `A` как фабрику для создания обычного объекта.

**Процесс:**
1. Вызывается `A.__new__()`.
2. Выделяется память под обычный объект (не `PyTypeObject`, а простая структура с заголовком).
3. В заголовок записывается указатель на `A`.

**Схема:**
```text
[ Класс A ]                     [ Экземпляр a ] (обычный PyObject)
(PyTypeObject)                  (Instance Object)
+---------------------+         +-----------------------------+
| PyObject_HEAD       |         | PyObject_HEAD               |
|  ... данные типа ...|         |  +-----------------------+  |
|                     |         |  | ob_refcnt = 1         |  |
| tp_call (функция)   |         |  | ob_type --------->---------+
+----------+----------+         |  +-----------------------+  |     |
           | (вызывает __call__) +-----------------------------+     |
           +-------------------> | | __dict__ = {}             |     |
                                 | | (место для атрибутов)     |     |
                                 +-----------------------------+     |
                                                                     |
                                         (ob_type экземпляра a указывает на Класс A)
```

### 4. Создание Переменной (`x = a`)
Как мы уже говорили, переменная — это не объект, а запись в словаре (`dict`).

**Схема:**
```text
[ Namespace / Globals ]         [ Экземпляр a ]
(PyDictObject)
+-------+----------------+      +-----------------------------+
| "x"   | Указатель ----------> | PyObject_HEAD               |
+-------+----------------+      |  ob_refcnt = 2 (теперь 2 ссылки)|
                                |  ob_type -> [Класс A]       |
                                +-----------------------------+
                                | __dict__ = {}               |
                                +-----------------------------+
```
> **Важно:** `ob_refcnt` увеличился с 1 до 2, потому что теперь на объект `a` ссылаются и переменная `a` (если была), и переменная `x`.

### 🧩 Итоговая схема (Всё вместе)

Давай соберём цепочку создания `x = MyClass()`:

```text
1. СУЩЕСТВУЕТ ЗАРАНЕЕ:
   [ type ] (Метакласс)
      |
      | (type.__new__)
      v
2. СОЗДАЁТСЯ КЛАСС:
   [ PyTypeObject: MyClass ]  <--- Это тоже объект в памяти!
      |  ^
      |  | (ob_type указывает на type)
      |  |
      |  (MyClass.__call__)
      v
3. СОЗДАЁТСЯ ЭКЗЕМПЛЯР:
   [ PyObject: instance ]
      |  ^
      |  | (ob_type указывает на MyClass)
      |  |
      |  (Связывание имени)
      v
4. ЗАПИСЬ В ДИКТЕ:
   { "x": -----> [ PyObject: instance ] }
```

### Ключевые выводы по схемам:
1. **Цепочка типов:** Экземпляр знает про Класс (`ob_type`), Класс знает про Метакласс (`ob_type`), Метакласс знает про себя самого (`type` -> `type`).
2. **Разные структуры:** Класс (`PyTypeObject`) гораздо тяжелее и сложнее экземпляра, потому что он хранит методы, базовые классы и дескрипторы. Экземпляр хранит только свои данные.
3. **Переменная — это ярлык:** В схеме 4 видно, что переменная `x` не является частью структуры объекта. Она лежит отдельно в словаре и просто "светит пальцем" на объект.
